# Important files

|File|Description|
|----|-----------|
|[`/smart_canvas/core.py`](/smart_canvas/core.py)|Handles the main control flow of the SmartCanvas application's application logic through a state machine that consumes image frames.|
|[`/smart_canvas/filters/carousel.py`](/smart_canvas/filters/carousel.py)|Defines the filters available in the application. Also see [ADDING FILTERS](ADDING%20FILTERS.md).|
|[`/web/__init__.py`](/web/__init__.py)|Loads and initalizes the Flask backend server|
|[`/web/main/events.py`](/web/main/events.py)|Defines the behavior when a client (frontend) connects to the server (backend).|
|[`/smartcanvas-frontend/App.tsx`](/smartcanvas-frontend/src/App.tsx)|Defines the behavior of the React frontend|
