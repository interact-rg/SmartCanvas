# Contributing

If you are a **student project** assigned to work on this:

1. Fork this repository.
2. Clone your fork to your local PCs.
3. Create new branches for fixes or new features.
4. Commit and push to your fork.
5. Test that your fix/feature works.
6. Make sure your work or components you use do not contain any known security issues (use e.g. Dependabot).
7. When you are finished with the project, create a pull request to this repository from your repo/branch.
8. Maintainers will then check your pull request, maybe suggesting fixes.
9. When all is OK, your fix/feature will be merged with this repo.

If you wish to contribute to this project with a **single new fix or feature**:

1. Fork this repository.
2. Clone your fork to your local PC.
3. Create a new branch for any fix or new feature.
4. Commit and push to your fork.
5. Test that your fix/feature works.
6. Make sure your work or components you use do not contain any known security issues (use e.g. Dependabot).
7. Create a pull request to this repository from your repo/branch.
8. Maintainers will then check your pull request, maybe suggesting fixes.
9. When all is OK, your fix/feature will be merged with this repo.

Technical questions can be asked from the maintainers (©anttijuu, @jlappala). Other questions, please approach the owner of this project.
